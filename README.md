# 医药科研投稿助手（MediSubmit）

面向医药科研人员的期刊投稿匹配工具：内置 1,573 本国外医药 SCI 期刊，支持按 JCR 分区、影响因子、OA/APC、学科、研究主题、稿件类型筛选，以及本地关键词初筛和 AI 语义推荐。

## 在线访问

GitHub Pages 部署后访问：`https://chantel-wang.github.io/MediSubmit/`

## 功能说明

- 📚 1,573 本期刊（2023–2025 发文量、ISSN、出版社、官网、OA/APC 等元数据）
- 🎯 关键词初筛 TOP5 / TOP30：本地即时计算，免费且无需联网
- 🤖 AI 语义推荐 Top5：需登录后使用（当前为演示登录）
- 📄 分页浏览、多条件组合筛选

## 部署与安全注意事项

- 本仓库只包含**静态前端**与期刊数据，不含任何 API Key。
- 本地 AI 服务（`local-ai-test/`）依赖 `智谱Key.txt`，该文件**已被 .gitignore 排除，绝不提交到仓库**。
- 在线版暂不提供 AI 推荐后端；如需要在线上使用 AI，请将智谱 Key 放入云端环境变量（如 Vercel / Cloudflare Worker），不要写进前端代码。
- 登录目前为演示模式（验证码在页面内显示），接入 Supabase 后可升级为真实邮箱验证码。

## 数据更新

期刊数据文件：`数据更新/journals.json`（网页优先加载）、`journals-data.js`（兜底数据）。年度 JCR 更新脚本保留在本地 `数据更新/` 目录。
